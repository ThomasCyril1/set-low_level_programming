# 0x04. More functions, more nested loops

This project contains C programs that demonstrate functions, nested loops, conditional statements, and character output using `_putchar`.

## Files

- `0-isupper.c` - Checks for uppercase characters.
- `1-isdigit.c` - Checks for digits.
- `2-mul.c` - Multiplies two integers.
- `3-print_numbers.c` - Prints numbers from 0 to 9.
- `4-print_most_numbers.c` - Prints digits except 2 and 4.
- `5-more_numbers.c` - Prints numbers from 0 to 14 ten times.
- `6-print_line.c` - Draws a straight line.
- `7-print_diagonal.c` - Draws a diagonal line.
- `8-print_square.c` - Prints a square.
- `9-fizz_buzz.c` - Prints the Fizz-Buzz sequence from 1 to 100.
- `10-print_triangle.c` - Prints a right-aligned triangle.
