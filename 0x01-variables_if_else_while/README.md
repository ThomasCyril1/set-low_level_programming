# 0x01. Variables, if, else, while

This project contains C programming exercises covering variables, conditional statements, loops, and character output.

## Requirements

- Ubuntu 20.04 LTS
- GCC compiler
- Compilation flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style

## Tasks

| File | Description |
|---|---|
| 0-positive_or_negative.c | Determines whether a random number is positive, negative, or zero. |
| 1-last_digit.c | Prints the last digit of a random number. |
| 2-print_alphabet.c | Prints the lowercase alphabet. |
| 3-print_alphabets.c | Prints lowercase and uppercase alphabets. |
| 4-print_alphabt.c | Prints the alphabet except q and e. |
| 5-print_numbers.c | Prints single-digit base-10 numbers. |
| 6-print_numberz.c | Prints single-digit numbers using putchar. |
| 7-print_tebahpla.c | Prints the lowercase alphabet in reverse. |
| 8-print_base16.c | Prints hexadecimal numbers in lowercase. |
| 9-print_comb.c | Prints single-digit numbers separated by commas. |

## Compilation

Compile an individual source file using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 filename.c -o filename
