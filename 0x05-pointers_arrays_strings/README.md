# 0x05. C - Pointers, Arrays and Strings

## Description

This project focuses on pointers, arrays, and strings in the C programming language. It covers how to manipulate memory addresses, access array elements, process strings, and write functions that work with pointers.

## Learning Objectives

- Understand pointers and how to use them.
- Understand arrays and how to manipulate their elements.
- Understand strings and how they are stored in memory.
- Use pointers to access and modify variables.
- Write functions that manipulate strings and arrays.

## Requirements

- Ubuntu 20.04 LTS
- GCC compiler
- Compilation flags: `-Wall -Werror -Wextra -pedantic -std=gnu89`
- Betty coding style

## Files and Functions

| File | Function | Description |
|---|---|---|
| 0-reset_to_98.c | reset_to_98 | Updates the value pointed to by an integer pointer to 98. |
| 1-swap.c | swap_int | Swaps the values of two integers. |
| 2-strlen.c | _strlen | Returns the length of a string. |
| 3-puts.c | _puts | Prints a string followed by a new line. |
| 4-print_rev.c | print_rev | Prints a string in reverse followed by a new line. |
| 5-rev_string.c | rev_string | Reverses a string in place. |
| 6-puts2.c | puts2 | Prints every other character of a string. |
| 7-puts_half.c | puts_half | Prints the second half of a string. |
| 8-print_array.c | print_array | Prints the specified number of elements of an integer array. |
| 9-strcpy.c | _strcpy | Copies a string from source to destination. |
