# 0x06. More Pointers, Arrays and Strings

## Description

This project focuses on pointers, arrays and strings in the C programming language. It explores string manipulation, character comparison, array reversal and character encoding.

## Files

| File | Description |
|---|---|
| `0-strcat.c` | Concatenates two strings. |
| `1-strncat.c` | Concatenates a specified number of characters. |
| `2-strncpy.c` | Copies a specified number of characters. |
| `3-strcmp.c` | Compares two strings. |
| `4-rev_array.c` | Reverses the contents of an integer array. |
| `5-string_toupper.c` | Converts lowercase letters to uppercase. |
| `6-cap_string.c` | Capitalizes all words of a string. |
| `7-leet.c` | Encodes a string into 1337. |
| `main.h` | Contains function prototypes. |

## Compilation

The source files are compiled using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

## Requirements

- Ubuntu Linux
- GCC compiler
- Betty coding style
- C programming language
