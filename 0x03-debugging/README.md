# 0x03. C - Debugging

## Description

This project focuses on identifying and correcting errors in C programs.

## Tasks

- **0. Multiple Mains:** Test the `positive_or_negative` function with zero.
- **1. Like, Comment, Subscribe:** Stop an infinite loop by commenting out the faulty loop.
- **2. 0 > 972?:** Correct the `largest_number` function to return the largest of three integers.
- **3. Leap Year:** Correct the date calculation to handle leap years and invalid dates.

## Compilation

The programs are compiled using:

`gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
