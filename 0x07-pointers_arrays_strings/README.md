# 0x07. C - Even more pointers, arrays and strings

## Description

This project focuses on memory manipulation, pointers, arrays, strings, and multidimensional arrays in C.

## Files and Functions

| File | Function | Description |
|---|---|---|
| 0-memset.c | `_memset` | Fills memory with a constant byte. |
| 1-memcpy.c | `_memcpy` | Copies memory from one location to another. |
| 2-strchr.c | `_strchr` | Locates a character in a string. |
| 3-strspn.c | `_strspn` | Calculates the length of an initial segment containing accepted bytes. |
| 4-strpbrk.c | `_strpbrk` | Searches for the first matching character in a string. |
| 5-strstr.c | `_strstr` | Locates a substring within another string. |
| 6-print_chessboard.c | `print_chessboard` | Prints an 8 × 8 chessboard. |
| 7-print_diagsums.c | `print_diagsums` | Calculates and prints the sums of a matrix's two diagonals. |

## Compilation

The source files are compiled using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

## Header File

`main.h` contains the function prototypes used throughout the project.
