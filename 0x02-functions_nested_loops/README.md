
# 0x02. C - Functions, Nested Loops

## Description

This project focuses on functions and nested loops in the C programming language.

It covers:
- Using functions and function prototypes.
- Working with nested while loops.
- Understanding character arithmetic and ASCII values.
- Using conditional statements.
- Performing arithmetic operations.
- Printing numbers and characters using `_putchar`.

## Files

| File | Description |
|---|---|
| 0-putchar.c | Prints `_putchar` |
| 1-alphabet.c | Prints the lowercase alphabet |
| 2-print_alphabet_x10.c | Prints the alphabet ten times |
| 3-islower.c | Checks for lowercase characters |
| 4-isalpha.c | Checks for alphabetic characters |
| 5-sign.c | Prints the sign of a number |
| 6-abs.c | Computes the absolute value |
| 7-print_last_digit.c | Prints and returns the last digit |
| 8-24_hours.c | Prints every minute of the day |
| 9-times_table.c | Prints the 9 times table |
| 10-add.c | Adds two integers |
| 11-print_to_98.c | Prints numbers from a given integer to 98 |

## Compilation

Compile the C files using:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```
